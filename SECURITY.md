# Security Policy

## Supported Versions

Currently the 1.x branch is the only supported version and any previous major versions will not receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you find a vulnerability in this software please disclose it responsibly by emailing security@thoughtcollective.com with details describing the issue, versions affected, and how to recreate it.
